## Where it's going

Companies that want AI without sending their data to a third party will run models on their own machines. This project is the management layer for a fleet of those machines: registering nodes, checking their health, and later deploying reusable AI agents to them.

## What works today

The first milestone focuses on the **Control Plane API**:

- A NestJS service in a Turborepo monorepo, with an operator dashboard (React and Vite) scaffolded alongside it.
- **Contract first.** The OpenAPI definitions live in a shared `contracts` package, and the API is implemented against them.
- **Persistence** with Drizzle ORM on PostgreSQL, run locally through Docker Compose.
- Node registration, the building block for everything that comes next.
