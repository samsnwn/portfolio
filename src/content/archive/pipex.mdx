The parent opens a pipe and forks two children. The first child replaces its stdin with the input file and its stdout with the pipe's write end, then runs `cmd1`. The second child reads from the pipe and writes to the output file. Each command is found by searching `PATH` from the environment.

```c
dup2(infile, STDIN_FILENO);
dup2(pipe_fds[WRITE_END], STDOUT_FILENO);
close(pipe_fds[READ_END]);
execve(path, args, envp);
```

**What I learned:** the groundwork for minishell. Above all, a child process has to close every file descriptor it doesn't need, or the pipeline never finishes.
