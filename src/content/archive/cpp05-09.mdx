- **05:** a bureaucracy built on exception classes (forms that can't be signed throw).
- **06:** the four C++ casts and type identification without `typeid`.
- **07:** function and class templates, including a templated `Array<T>`.
- **08:** STL containers with iterators, such as `easyfind` and a `MutantStack` that can be iterated.
- **09:** three real programs. A Bitcoin price lookup using `std::map::lower_bound`, an RPN calculator built on a stack, and **PmergeMe**, a Ford-Johnson merge-insertion sort implemented on both `std::vector` and `std::deque` to compare their performance.

**What I learned:** to choose containers based on their access patterns, and that the textbook complexity of an algorithm doesn't always predict how fast it runs on real hardware.
